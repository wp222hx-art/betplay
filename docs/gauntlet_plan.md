# 「逐个揭晓 · 淘汰赛」通用玩法（从致命13 提炼）

## 一、致命13 为什么好玩（6 条可复用的内核）
1. **一群看得清的人**：每人一张脸、一个号码、一个名字，底部头像条全程可见
2. **规则一句话、风险公开递增**：第 k 轮装 k 发（每人危险 k/6），玩家自己能估算
3. **同时决定、逐个揭晓**：结果开局锁定，但演出时一个接一个开：咔 / 咔 / 砰——每一下都是心跳
4. **押的是「还剩几个」**：屏上 8 秒、三档、赔率 = 真实概率；押错不出局，下一轮接着押
5. **逐轮淘汰到最后对决**：人越来越少 → 镜头越来越集中 → 决斗押谁活
6. **连中奖励 + 局局衔接**：3 连中爆奖池；结束倒计时自动下一局

## 二、通用引擎（一套代码，每部剧只写配置）
| 参数 | 说明 |
|---|---|
| `cast[N]` | N 个参赛者（6~13 人）：脸、名字、号码 |
| `risk(k)` | 第 k 轮每人「出局」概率（公开），如 k/6、0.15k |
| `reveal` | 每人 2 段片：`out{i}`（出局）/ `safe{i}`（过关），同机位、首尾帧锁定 |
| `round_clip(k)` | 每轮开场「上膛」式仪式片（风险可视化） |
| `final` | 剩 2 人对决；`winner{i}` 收尾 |
| 押注 / 连中 / 奖池 / 公平验证 | 全部沿用致命13（survivorDist 分档、rtp 94%、HMAC 种子） |

## 三、7 部剧改造方案（规则度 × 博弈度）
### 惊心1分钟
| 剧 | 一句话规则 | 每轮仪式（风险可视化） | 逐个揭晓 | 出局 / 过关 | 对决 |
|---|---|---|---|---|---|
| **坠梯**（试点） | 8 人困在失控下坠的电梯里；每坠一层，门弹开一条缝，大家依次往外挤；押「这一层之后电梯里还剩几人」 | 楼层灯跳一格、钢缆火花，门缝一层比一层窄（第 k 层挤不出去的概率公开，逐层上升） | 一个接一个扑向门缝 | 挤出去（滚进走廊得救）/ 门「哐」地合上把他弹回来 | 最后 2 人、最后一道缝：谁挤出去，另一个随电梯坠入黑暗 |
| **人质谈判** | 劫匪手里 8 个人质，每轮谈判他只放「抽到白球」的 | 劫匪往袋里多加一颗黑球 | 人质依次伸手摸球 | 白球 = 走出银行 / 黑球 = 被按回地上 | 最后 2 人：劫匪只放一个 |
| **最后一把** | 8 个赌徒，每轮翻一张牌，小于桌上那张的人出局 | 荷官翻开「门槛牌」，一轮比一轮大 | 依次翻牌 | 大 = 推筹码继续 / 小 = 推开椅子离桌 | 最后 2 人比一张 |

### 开心1分钟（同样的紧张节奏，结局是笑点）
| 剧 | 一句话规则 | 每轮仪式 | 逐个揭晓 | 出局 / 过关 |
|---|---|---|---|---|
| **摸鱼大逃杀**（动物世界改） | 10 个打工人，老板每轮巡逻一圈，被抓到摸鱼的出局 | 老板脚步声一轮比一轮快 | 老板依次走过每个工位 | 秒切工作界面 / 被抓（手机掉地、外卖露馅） |
| **抢车位**（老爸倒车 + 阿木合并） | 8 个司机抢 1 个窄车位，依次倒车，刮蹭即出局 | 车位每轮再窄 10cm | 依次倒车 | 稳稳停进 / 「咔」刮到柱子 |
| **霸总选妃**（霸总求婚改） | 8 位求婚者依次单膝跪地，霸总每轮只留一半 | 戒指盒一轮比一轮小 | 依次跪下递戒指 | 收下 / 「下一位」 |

## 四、制作量与成本（每部）
- 8 人 × 2 段（出局/过关）= 16 段 + 仪式 3 段 + 开场 1 + 对决 2 + 胜者 8（可复用过关段尾帧，改 4 段）≈ **26 段**
- ≈ 26 × 940 ≈ **2.4 万积分 / 部**（含定妆图）；6 部 ≈ 14.5 万
- 先做 1 部试点 → 你确认手感 → 批量

## 五、试点建议：坠梯
- 你点名「电梯坠落」的紧张感；8 人 + 门缝 + 楼层灯，规则一眼看懂
- 无血腥：出局是「门合上被弹回」，最后坠落用刹车火花 + 黑屏，安全过审
